四国争霸 2.1 · DLC 版 —— 离线运行包

先看简介：简介.html（137 张战术卡怎么用、哪些最好玩）
规则与界面详解：介绍.html
两个页面双击就能在浏览器里打开。

在线玩：https://guiren684.github.io/junqi-chaos/

1. 双击 index.html，用 Chrome / Edge 打开（推荐）。
2. 如果双击后页面空白或提示脚本被拦，说明浏览器禁止了本地文件脚本：
   - 用 Chrome 打开 chrome://extensions 确认没有禁用本地脚本的策略；或用任意静态服务器：
     在本目录执行  python -m http.server 8000  然后访问 http://localhost:8000
   - 或者把整个文件夹拖进 Edge/Chrome 也可以。
3. 不需要联网，不需要安装任何东西（纯静态页面）。
4. 存盘/阵法库保存在浏览器 localStorage 里，换电脑后不会跟过来。

【局域网开黑】
1. 房主电脑装 Node（其它人不用），在本目录执行：
     node lan_server.js            （默认 8080 端口，用 --port 9000 可改）
   它会打印一个 http://192.168.x.x:8080/ 的地址。
2. 大家用浏览器打开这个地址（不是双击 index.html），点顶部「局域网」→ 创建/加入。
3. 房主点「开始对局」。人不够的座位由 AI 补上；两个人默认坐南北（同队）。
4. 对局中刷新页面会自己回到原座位；房主关掉页面这局就结束了。
5. 想要纯军棋：取消控制区的 DLC 勾选即可（本包默认开启）。
6. 用主动卡前会先问 2 道抗美援朝英雄事迹题：答对越多等级越高（Ⅰ→Ⅲ），答错不扣牌；
   不想答题就取消控制区的「答题定级」勾选。
